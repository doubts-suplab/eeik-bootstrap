# Platform Engineering Capability Pack

Internal developer platforms (IDP) that make the right way the easy way.

| Provides | |
|---|---|
| Agents | `platform-engineer` |
| Standards | `platform-engineering-standard` |
| Resolves when | `delivery.platform_engineering: true` (opt-in) — also add via `capability_packs.include: [platform-engineering]` |
| Depends on | `core`, `architecture` |

Golden paths / paved roads, self-service scaffolding and infrastructure, a Backstage-style developer
portal, and the thinnest-viable-platform principle — treating the platform as a product with developers
as its customers. Grounded in Team Topologies (reduce cognitive load on stream-aligned teams).

See [`standards/platform-engineering-standard.md`](standards/platform-engineering-standard.md).
